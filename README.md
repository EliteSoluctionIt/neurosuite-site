# NeuroSuite public website

This repository contains the public presentation website served at
[neurosuite.dev](https://neurosuite.dev).

## Scope

Only public, presentation-layer assets belong here. The repository does not
contain NeuroSuite product source code, analytical models, algorithms, health
data, credentials, private documentation, or reserved-access material.

The production website is published from the `main` branch through GitHub
Pages. Changes should be reviewed through a pull request and must preserve the
responsive blue-and-gold visual identity.

## Security

Do not publish secrets, personal data, test exports, simulated identity flows,
or private-room prototypes in this repository. Report security concerns
privately to [info@neurosuite.dev](mailto:info@neurosuite.dev).
