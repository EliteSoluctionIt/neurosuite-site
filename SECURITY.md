# Security policy

This repository contains only the public NeuroSuite website.

Please do not disclose suspected vulnerabilities, credentials, personal data,
or other sensitive information in a public issue. Send reports privately to
[info@neurosuite.dev](mailto:info@neurosuite.dev), including the affected URL,
the observed behavior, and the minimum steps needed to reproduce it.

NeuroSuite will acknowledge legitimate reports and assess remediation as soon
as practical.
